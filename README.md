# zhvaev.ru — личный сайт-визитка

Никита Жваев — QA-инженер, геймдизайнер, автор.

Статический сайт. Швейцарский минимализм, светлая/тёмная темы,
кастомный курсор, реактивный фон и плавные анимации.

## Структура
- `index.html` — разметка
- `styles.css` — стили и дизайн-токены (темы, типографика, сетка)
- `app.js` — интерактив: курсор, параллакс, scroll-reveal, переключатель тем, лайтбокс
- `assets/` — аватар и сканы дипломов/сертификатов
- `CNAME` — кастомный домен (zhvaev.ru)

## Деплой (GitHub Pages)
1. Залить содержимое этой папки в корень репозитория.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Custom domain: `zhvaev.ru` (берётся из файла `CNAME`).

## Замена контента
- Аватар: `assets/avatar.jpg` (квадрат, ~600×600).
- Сертификаты: `assets/cert-*.jpg`. Подписи и порядок — в секции «Дипломы и сертификаты» в `index.html`.
- Тексты: правятся прямо в `index.html`.
